Glossary & Learning Resources

Essential terms and trusted places to learn more.

Algorithm

A finite sequence of well-defined steps for solving a problem.

Array

An indexed collection of elements.

Binary

A number system that uses the digits 0 and 1.

CPU

The Central Processing Unit, which executes program instructions.

Data structure

A way to organize and store data for efficient use.

Graph

A structure consisting of vertices and edges.

Logic

A formal method of reasoning about statements and their truth values.

Queue

A data structure that generally follows First In, First Out (FIFO).

Stack

A data structure that generally follows Last In, First Out (LIFO).
