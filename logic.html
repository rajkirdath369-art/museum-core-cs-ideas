EXHIBIT 04 · MATHEMATICAL FOUNDATIONS

Logic & Discrete Mathematics

Precise reasoning is part of computing.

Discrete mathematics studies distinct or countable structures. It provides tools for reasoning about algorithms, digital circuits, databases, and networks.

Propositional logic

A proposition is a statement that is either true or false. Logical operators combine or modify propositions.

Sets

Collections of distinct objects.

Relations

Connections between elements of sets.

Functions

Rules associating each permitted input with an output.

Combinatorics

Methods for counting arrangements and selections.

Graph theory

Vertices and edges used to represent networks.

Boolean logic

Logical values and operations used in digital design.

Applications in computing

  • Boolean logic helps design digital circuits.
  • Sets and relations help describe database concepts.
  • Combinatorics supports counting and probability.
  • Graph theory models networks and routes.
