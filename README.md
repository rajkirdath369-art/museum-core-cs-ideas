# The Museum of Core CS Ideas — Website Package

This is a complete static website prototype with 10 pages, responsive navigation, a modern navy-and-gold visual system, original SVG diagrams, and a working four-question quiz.

## Open the site
1. Extract `museum_core_cs_ideas.zip`.
2. Open `index.html` in a current browser.
3. Navigate using the top menu. No installation or internet connection is needed for the local site itself; external resource links need internet.

## Important distinction
This package is a working website prototype, **not a site created or published in your Google account**. Google Sites does not import a folder of HTML/CSS/JavaScript as a native editable site. To make a native Google Site, recreate the pages using the Google Sites editor and paste the provided copy; upload or recreate the SVG diagrams as appropriate.

## Google Sites build order
1. Visit https://sites.google.com/ and create a blank site.
2. Create these pages: Home, The Exhibits, Algorithms & Problem Solving, Data Structures, Inside the Computer, Logic & Discrete Mathematics, History of Computing, Glossary & Learning Resources, Mini Learning Lab, About the Project.
3. Nest the four exhibit pages under The Exhibits.
4. Use the HTML pages as content references; paste each page's headings and copy into Google Sites text boxes.
5. Rebuild the cards with Google Sites layouts and insert the SVG diagrams from `assets/` if the editor accepts them, or export them to PNG first.
6. Recreate the quiz using Google Forms if you want the quiz embedded in Google Sites.
7. Preview desktop/mobile, check link and image permissions, then publish manually.

## Before academic submission
- Confirm the subject/course and faculty-guide fields in `about.html`.
- Verify the institution and academic details.
- Add sources for technical and historical information you actually consult.
- Check image licence/attribution requirements.
- The site uses no third-party photos; its diagrams are original SVGs.
